## 变更规则

用户改变约束时新增编号，记录被覆盖编号、原因、影响版本和需要同步的文档。实施默认值的修改可由 Agent 留技术证据后完成；涉及 API 不兼容、存储职责变化、版本重排或降低硬性质量标准，需用户明确决定。

逐版验收通过后的本地合并 main 已包含在用户要求的开发流程内，无需重复确认。v1已验收并本地合并；当前没有授权自动推送、创建远端仓库或发布。文档提交属于本地开发记录，不代表新业务版本完成。

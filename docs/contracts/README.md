# 契约入口

契约按版本保存，绑定固定旧版源码提交，不随参考分支移动自动变化。

| 版本 | 文档 | 证据状态 |
| --- | --- | --- |
| v1 | [v1 文档 CRUD 契约](v1.md) | 已提取源码契约，尚无原版运行快照 |
| v2–v21 | 在对应版本启动时逐版建立 | 未开始 |

“源码推导”与“运行验证”必须分开标记。之后生成的匿名夹具放 `tests/fixtures/contracts/vN/`，包含来源版本、配置、输入、响应和归一化规则；当前尚未生成该目录和夹具。

执行方法和差异处理见 [兼容策略](../refactor/compatibility.md)。
